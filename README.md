# مِحْبَرَة الأخبار والشريط الإخباري

تطبيق ويب عربي سريع وخفيف لتحرير الأخبار وتفكيك النشرات الإخبارية إلى شريط إخباري، مبني ببنية ملفات منفصلة (`Lazy-Loading`) ومتوافق مع النشر على **Vercel**.

## هيكل الملفات
- `index.html` — الواجهة الرئيسية الخفيفة.
- `assets/` — ملفات التنسيق (`style.css`) والمحرك البرمجي (`app.js`).
- `data/news-rules.json` — قواعد تحرير الأخبار المعتمدة.
- `data/ticker-rules.json` — قواعد تفكيك النشرات والشريط الإخباري.
- `data/dictionary.json` — قاموس التصويبات اللغوية والممنوعات الإملائية.
- `data/news-examples/` — ملفات منفصلة لأمثلة الأخبار (خبر خام ⬅ خبر محرر).
- `data/ticker-examples/` — ملفات منفصلة لأمثلة النشرات (نشرة خام ⬅ شريط إخباري).
- `api/ai.js` — جسر سحابي خفيف على Vercel لتمرير طلبات النماذج وتجاوز الحجب الجغرافي دون حفظ أي مفاتيح في الكود.
